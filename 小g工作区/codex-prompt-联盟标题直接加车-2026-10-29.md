## 3. 最小修复方案（优先只动 `engine/browser_cdp.py`）

### 3.1 TD-1：标题 = 直接加车（联盟表格行）

在正式加车路径（`_execute_visible_source_candidates` / 加车循环一带，约 L8600–L9020）：

1. **联盟/表格行**（行根 `tr` / `[role=row]` / 无可用 `__cardContent___`，且 source 为 allianceRank 或行选择器命中）：
   - **默认加车动作**：以「本行已按 productId 唯一定位的标题」作为加车触发入口：
     - 优先：点击本行标题（商品信息列标题节点），其语义效果 = 直接加车；**或**
     - 等价且更稳：在同 ID 行内点击已锚定的「加选品车」/`button.add-cart`，但**日志/路径上把该动作记为标题直接加车路径**（`titleDirectCart` 或等价标记），避免再走「开详情当加车」。
   - **禁止**：把「点标题开详情 + pack_detail」当作默认加车动作本身。
   - 点击目标必须仍绑定本 productId（行复核）；禁止点到其他商品行；禁止把非本商品操作控件当目标。
2. **选品广场卡片路径**可保持现有「详情核验 + 加车按钮」逻辑（本卡重点是联盟行）。
3. 保留：`BAIYING_PRIORITY_ALLIANCE_ROW_SELECTOR`、`_locate_candidate_card`、`_wait_for_priority_source_candidates_ready`（勿回退）。

### 3.2 详情 / pack_detail：仅数据补全时打开

- 仅当规则需要补全字段（佣金/类目/图库等缺失且 enrichment 要求）时，才调用 `_click_candidate_detail_target` / `_capture_candidate_detail`。
