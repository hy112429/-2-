# 确认加车后自动下载同款带货视频

日期：2026-11-07。来源：用户确认“选品最终加入选品车”与商品 ID 下载视频重叠执行；选品用哪个百应账号，下载就用哪个账号并自动分类。

## 当前流程

1. 软件收到百应明确的 `cartAdded=true`，且该商品在本机选品登记结算为 `ADDED` 后，直接取回该账号 ID、商品 ID 和百应推广 ID。跳过、拒绝、结果不明及登记未结算的商品不触发下载。
2. 主进程异步读取该账号专属 Chrome 的百应「带货内容」，按该账号设置的每商品额度获取同款带货作品。下载与后续商品详情图转视频、发布流程并行；同账号多个商品依次下载，避免同时打开大量商品页。
3. 已在素材库登记为同账号、同商品 `web_download` 且文件仍存在的视频 ID 不重复下载。新增 MP4 存入账号下载路径下的 `{日期}/{商品ID}/{商品ID}_{视频ID}_{序号}_{时间戳}.mp4`；未设置账号路径时，账号路径为 `{全局下载根目录}/账号-{账号ID}`。
4. 抖音作品确认 `published` 后，原有 P-33 流程先等待同商品正在进行的加车下载，再优先把已下载且符合 Step 17 资格的最多 3 条素材加入千川队列。无可复用素材时，沿用原千川授权查询及下载流程。`submitted_review` 仍不触发 Step 17。
5. 下载失败不回滚已确认的加车。可在“商品查询”用该商品 ID 重新查询下载；千川上传仍受原有账号绑定、发布确认、额度和素材资格规则约束。

## 验证与尚待实机验收

- 隔离测试：`desktop/scripts/test_baiying_cart_download.cjs` 验证账号归属、已入库视频跳过和重复触发；`desktop/scripts/test_post_publish_qianchuan_material.cjs` 验证发布后复用、账号隔离和不重复下载。2026-11-07 两项均通过；客户端 `npm run build` 通过。
- 实机验收：在已登录百应的专属账号下选一个新商品，确认加入选品车；检查该账号分类目录出现同款带货 MP4，素材库账号/商品/来源均正确。重走同一商品不得新增重复文件。之后仅在对应抖音作品确认为 `published` 时，检查 Step 17 入队的是该账号已下载的合格素材。真实平台全链路结果尚未记录，不能把隔离测试视为已验收。
