# 千川真实投放流程复刻（2026-11-11）

来源：`巨量千川 - Google Chrome 2026-11-11 17-58-34.mp4`。

视频时长约 76 秒，录制的是巨量千川“商品全域投放”创建计划的主体流程。视频中省略了三段真实操作：素材视频实际上传、标题实际填写/上传、最后点击“发布计划”。因此以下流程把可见步骤和省略步骤合并记录，不能把省略段误判为已实机通过。

## 一、视频中确认的页面顺序

1. 进入巨量千川首页，在全域投放数据区域进入“竞价投放 → 推商品”。
2. 点击“投放商品”，进入“商品全域投放”创建页。
3. 在“选择商品”中打开“添加商品”，按商品名称或商品 ID 搜索，勾选目标商品并点击“确定”。视频中选中 1 个商品，页面显示商品 ID。
4. 在“投放设置”中选择“控成本投放”。
5. 填写“净成交 ROI 目标”。视频展示系统建议值 4.95，页面公式为“净成交金额 ÷ 整体消耗”。
6. 填写“投放日预算”。视频先出现 50 元，后续又演示改成 10000 元；客户端必须保留预算由甲方调整，并在最终发布前再次确认。
7. 选择投放时间。视频选择“从今天起长期投放”。
8. 保留或调整“智能优惠券”等投放开关。
9. 进入“素材设置”，在“智能优选素材”和“自选投放素材”中选择素材策略，并选择素材所属商品。
10. 在素材区域添加视频、商品图片或图文。平台提示至少需要包含一个非抖音主页视频或非抖音主页图文。
11. 在标题区域点击“添加标题”，填写或选择系统推荐标题。视频只展示了入口和输入框，没有实际填写内容。
12. 在“计划信息”中确认计划名称。平台会自动生成类似 `2026-11-11_商品全域投放_17:58:46` 的名称。
13. 最后点击“发布计划”。视频只展示了按钮，没有实际点击，也没有计划 ID 或发布成功回执。

## 二、需要插入的自动化步骤

客户端的一键流程应把素材处理插入第 9 步“素材设置”之前完成：

1. 从百应/抖音同账号来源自动下载本地 MP4。
2. 进入千川“工具 → 全域投放 → 素材管理 → 视频库”，按商品 ID 和完整文件名核对目标素材。
3. 找不到同名素材时上传本地 MP4；等待全部文件显示完成后再确认。
4. 每条素材独立回读千川素材 ID，并检查 ID 唯一、广告主归属和商品归属。
5. 已存在的同名素材直接复用远端 ID，不能重复上传。
6. 有文件选择或提交结果不明的任务进入 `needs_review`，先人工核查，不能盲目重传。

## 三、最终自动化顺序

```text
进入全域投放/推商品
→ 按商品 ID 选择投放商品
→ 选择控成本投放
→ 填写或确认净成交 ROI
→ 填写或确认日预算和投放时间
→ 自动下载本地视频
→ 千川视频库按商品 ID 定位并上传/复用素材
→ 回读唯一千川素材 ID
→ 在素材设置中选择商品和视频
→ 添加并核对标题
→ 生成计划名称
→ 甲方最终确认预算和 ROI
→ 点击发布计划
→ 回读唯一千川计划 ID 和计划状态
```

## 四、验收边界

- 仅看到页面按钮、列表行或上传窗口，不能算上传成功。
- 只有回读到千川素材 ID，才算素材上传完成。
- 只有回读到千川计划 ID，才算计划发布完成。
- 本视频没有证明素材上传、标题提交和计划发布已经实机成功；这些步骤需要在后续真实测试账号上单独验收。
