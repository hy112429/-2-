## 项目定位与技术约束

这是 Windows 桌面客户端「投广管理客户端」（TouGuang-Client），目标业务链路为：百应选品 → 加入选品车 → 保存商品 ID/链接 → 获取商品素材 → 图转视频 → 抖音创作者中心发布准备 → 千川上传素材。

技术栈固定为 Electron + Vue 3 + TypeScript + Vite；Python、Playwright、yt-dlp、FFmpeg、OpenCV；本地 SQLite 且数据库变化必须增量迁移；服务端后续采用 Spring Boot + MySQL + Redis。不得擅自换栈。
