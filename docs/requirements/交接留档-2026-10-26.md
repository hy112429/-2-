## 4. 已锁定决策（关键口径）

**技术栈**
- 客户端：**Electron + Vue3 + TypeScript**
- 处理引擎：**Python**（`yt-dlp` / `FFmpeg` / `OpenCV` / `Playwright`），作为客户端伴生进程
- 服务端：**Spring Boot + MySQL + Redis**（集中式；中心只存元数据与缩略图，**视频文件存客户端本地**）

**规模（R16-2/R16-3）**：**20 台 × 每台 10 个抖音账号 ≈ 200 账号**；抖音发布 ≈ **1000 条/天**；**千川素材单台 500 条/天、全中心约 1 万条/天**（配额三层：每品≤10 条、每账号≤5 品/≤50 条、每 5 账号≤25 品/≤250 条；扩容策略见 SRS G.12）

**流程口径**
- 发布：**浏览器自动化**（抖音无开放发布 API）；**每台机器各自上传**（不做集中发布机）；**抖音发布＝商品详情图转视频（先）、千川素材＝网页下载素材（后）**（R17 / A-29）；**抖音自动发布脚本（A-25）R18 确认本阶段实施**
- 离线补偿（A-20）：**需要，定为「顺延补发」**（错过的任务开机后补发，跳过/顺延可配）
- 授权（A-21）：**服务端校验 + 心跳**（R-13 授权被绕过风险）
- 指纹（FR-G7-01）：**一账号一指纹隔离**（非字面的指纹复用）
- 账号与权限（A-16 / R18）：**权限模型＝层级（代理层级）× 职能（管理员 / 运营 / 只读）**；**权限项＝可配置原子权限字典（SRS 附录 I · 初版 58 项，可增删）**；**服务端强校验**（前端仅隐藏 / 置灰）；**代码只认 key** → 后续增删权限＝改配置，改动成本最低
