## 0. 使用说明（先看这段，很重要）

### 0.1 核心节奏

**一次只跑一步。** 跑完 → 自己验证 → 通过了再发下一条。不要把 10 步一口气全丢给 AI。

| 原则 | 说明 |
|---|---|
| 一步一验收 | 每步都有「✅ 验收标准」，不通过不往下走 |
| 先验风险，后搭界面 | Step 1–2 是**技术预研**，先把最可能失败的事验证掉，再写界面 |
| 用报错对话 | 不会调试没关系，**把完整报错原样贴给 AI**，让它定位 |
| 会话会变长 | 上下文太长时，让 AI 先输出「当前进度摘要」，然后**开新会话**把摘要 + 开场 Prompt 一起发 |

### 0.2 标准工作流

```
发【开场 Prompt】→ 发【Step N Prompt】→ AI 给方案+代码 →
你执行 → 成功：进入 Step N+1 ／ 失败：贴报错 → AI 修 → 再执行
```

## 1. 开场 Prompt（每次新建会话都要先发这一段）

```text
你是一名资深全栈工程师，协助我开发一个 Windows 桌面客户端「投广管理客户端」。

【项目背景】
- 用途：抖音电商选品 → 抓取商品视频 → 去水印 → 转码 → 批量下载入库
- 我是一人团队，用 AI 辅助开发，我会边做边学
- 我的技术水平：基础。所以请把每一步讲清楚，给出完整命令和完整文件内容，不要省略、不要用"此处略"

【技术栈（已锁定，不要擅自更换）】
- 客户端：Electron + Vue3 + TypeScript + Vite
- 处理引擎：Python（yt-dlp / FFmpeg / Playwright），作为客户端伴生进程
- 本地存储：SQLite

【已确定的规格约定】
- 下载目录：{根目录}/{账号}/{日期}/{商品ID}/
- 文件命名：{商品ID}_{视频ID}_{序号}_{时间戳}.mp4
- 视频规格：保留原始最高分辨率（≤1080p）；MP4 封装 + H.264 视频 + AAC 128kbps 音频
- 去水印策略：优先抓取平台无水印源；取不到则裁剪水印区；再不行模糊遮盖
- 界面语言：中文

【工作方式要求】
1. 每次只做我指定的这一步，不要顺手改别的文件
2. 先给 3–5 行方案说明，再给完整代码
3. 所有命令给出可直接复制的 PowerShell 完整形式
4. 引入新依赖时，先说明为什么需要它
5. 不确定的地方先问我，不要自己假设
6. 每步结束时告诉我：**如何验证这一步成功**（给出具体操作和预期结果）
```

1. 如何创建虚拟环境、安装依赖、运行脚本（完整命令）

## 5. 用 AI 的几条禁忌（新手最容易踩）

| 禁忌 | 后果 | 正确做法 |
|---|---|---|
| 一口气让 AI 写整个项目 | 代码越多越失控，出错了不知道从哪查 | **一步一验收** |
| 不看代码直接复制运行 | 出错时完全无法定位 | 至少让 AI 逐段解释关键逻辑 |
| 让 AI 换技术栈 | 前面积累全部作废 | 技术栈已锁定，不许改 |
| 报错只贴一句"报错了" | AI 只能瞎猜 | 贴**完整**报错 + 执行命令 + 环境 |
| 会话无限延续 | 上下文过长后 AI 开始忘事、乱改 | 及时输出进度摘要，**开新会话** |
| 做完不跑就往下走 | 错误层层累积，最后无法收拾 | 每步必跑、必验收 |
