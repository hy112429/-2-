## 本次找到的断点

1. 发布后自动素材编排完成并不代表计划已创建。计划任务需要素材上传终态、同账号商品佣金率、已启用的千川计划配置和至少 50 元日预算。
2. 自动计划调度此前只检查已经打开的千川/抖音浏览器。窗口关闭时任务保持“待发布”，调度器不会自行复用已有登录 profile 启动浏览器；失败原因只写主进程控制台，计划页没有明确原因。
3. 自动计划调度此前每轮只提交一条计划后返回，剩余商品至少要等下一个 60 秒周期才继续。大量商品/多账号时排队会显得很慢。
4. 计划提交点击后的未知回执会进入待核查。此时继续对同一个广告主提交其他计划会扩大重复投放风险，必须暂停该广告主并先核对。

## 本次改动

- 计划任务自动复用已经打开的千川专属 profile 或绑定抖音账号 profile。若对应浏览器未打开，仅当该客户端 profile 已有 `Default` 目录才尝试启动，避免自动创建空白浏览器并误以为已有登录态。
- 计划完成后关闭本轮由客户端自动启动的浏览器。已由用户打开的浏览器不会被关闭；遇到登录/验证/广告主不匹配或提交结果待核查时保留窗口，便于操作员处理。
- 自动调度从队首寻找未处理任务，逐条串行执行全部自动待发布计划，并继续处理到期的原计划素材补充任务。重新从队首查询，避免任务状态变化导致分页偏移跳过后续商品；没有登录资料或暂时不能运行的任务本轮只尝试一次，不挡住其他账号任务。
- 新增 `PLAN_DEFERRED` 事件。无法启动已有 profile，或同一广告主有待核查计划时，任务保留在待发布状态，原因在计划详情可见；成功开始提交后清除此前等待原因。
- 对存在 `needs_review` 计划的千川广告主暂停后续自动计划；其他广告主继续排队。待核查状态不自动点击发布、不重复重试。
- 更新计划页提示，区分账户自动任务与需人工确认预算的手动任务。

## 真实验收规则

每个计划只有在千川平台回读到唯一远端计划 ID 后才记为“已发布”。本次未登录浏览器、未上传素材、未建计划、未触发真实投放，也未打包。

自动队列仍遵守现有启用边界：千川账户必须先开启自动计划并配置至少 50 元日预算；自动同步只收录启用时间之后确认发布的商品，且要求素材上传已结束、存在有效远端素材 ID、同账号佣金率有效。启用前已发布的历史商品不会被自动补建计划，避免启用设置时意外对旧商品投放；如需补发，应在计划工作区逐项检查后生成手动任务。

后续 A 端验收需在明确的测试广告主上核对：

1. 准备至少两个已发布商品、同账号的已上传素材、有效佣金率和每个广告主已保存的预算/自动发布配置。
2. 关闭该账号浏览器但保留已登录的客户端专属 profile，观察自动任务是否只启动一个浏览器、创建计划后关闭，再处理下一商品。
3. 对照计划列表中的商品 ID、日预算、ROI、选入素材 ID 和千川远端计划 ID；确认多个商品均按队列完成，没有重复计划。
4. 用隔离/可控失败方式验证未登录、广告主不匹配、缺少素材时留在待发布或发布前停止；模拟提交回执不明时进入待核查，并只暂停同广告主的后续自动计划。
