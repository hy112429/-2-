# 更新记录

## v0.0.10 — 2026-11-02

- 安装器改为向导模式，安装时可以选择软件安装目录。
- 安装仍按当前 Windows 用户执行，不需要管理员权限。
- 安装包内置独立 Python 运行时和客户端需要的 Playwright、NumPy、OpenCV、FFmpeg、FFprobe 运行组件，避免依赖开发机的 Python 安装位置。
- 修复百应浏览器桥接子进程未继承 Python 运行环境的问题；启动前检查打包暂存依赖。
- 客户端顶部版本号读取实际应用版本。
- 包含选品、素材、发布队列、千川管理和本机发布调度相关功能。

### 路径行为

软件安装位置、客户端数据目录和素材保存目录是独立设置。改变安装位置不会改变素材保存目录；新建选品批次按当前已保存的通用或账号下载路径保存。恢复已有批次时继续沿用该批次确认过的目录，已下载素材不会搬迁。
