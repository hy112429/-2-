## 一、项目定位

抖音电商**选品素材自动化流水线**：把「人工下载视频 → 去水印 → 转码 → 批量入库」变成一条自动化链路。
形态：Windows 桌面客户端（Electron + Vue3 + TypeScript），Python 伴生引擎，本地 SQLite 记账。
当前正扩展至**自动化选品决策**（榜单优先 → 数据分析 → 销量上升/营业额高则入选）。

### 4.2 小红书水印结论确诊
- keketoys 水印 = **博主烧录的内容水印**（防盗用），CDN 无无水印版本，解析/下载层无法去除（铁证：流 URL md5 与 size 精确匹配官方主视频流）
- 两类小红书水印：①平台「小红书」三字水印（预览流 stream_type 19 带）；②博主内容水印（素材自带，无解）
- 修复：`_extract_note_id` + title 提取兼容 `/discovery/item/` 路径（实测 note_id/title 正常）
- alpha 反推/delogo 实测均无法干净去除（接近不透明白字是原理性极限）

### 4.3 T-05 关闭
- 规格改「最高可得画质」：合规边界内抖音分享链接最高 720p（匿名单候选 + yt-dlp 撞签名墙 403 双路实测）
- 1080p 在商业源已实现（百应 pack_detail 实测 1080x1920 无水印）

### 4.4 AI 去水印功能复活（Moonshine-Image）
- 技术路线：SLBR 自动检测水印 mask → 连通域后处理（thr=100/pad=15）→ LaMa 生成式填充 → 保留音轨
- 环境：`D:\software\moonshine\`（模型 slbr 85.8MB + big-lama 205.7MB 已 SHA256 校验；源码 Moonshine-Image-main.zip）
- **DirectML 判定不可用**：Arc A750 上 torch-directml 算子比 CPU 慢 10-15 倍（conv2d 0.50s vs 0.03s），0.2.6.dev 无 Windows 新版 → 弃用
- **纯 CPU 方案（用户拍板）**：低分辨率检测（360 宽）+ 原分辨率局部填充 + 多进程并行
- 速度：单进程 ~15s/帧；4 进程预估 ~4.5s/帧 → 15 秒视频约 20-30 分钟（后台任务）
- 效果 PASS：keketoys 完全去除、画面自然零误伤（5/5 清除、4.5/5 自然度）
- 交付：`engine/remove_watermark_ai.py`（白名单）+ engine.ts `SCRIPT_PYTHON` 解释器映射 + UI「AI去水印」按钮/进度区
- 适配细节：Python 3.13 imghdr shim、gpu_device 参数、checkpoint CPU 加载、inference_mode→no_grad、跨盘 shutil.move

### 4.5 自动化选品需求（新，用户规则 v1，待开发）
```
① 数据源优先级：罗盘榜单（视频/商品/达人/直播）→ 优先；榜单无合适 → 百应选品广场（非榜单）
② 预订候选：榜单/广场商品 → 「预订」加入候选池
③ 数据分析：对候选商品持续采集指标快照（销量、营业额 GMV、趋势）
④ 决策：销量上升 或 营业额高 → 入选推荐（触发抓素材/下载）
```
- 数据依赖：罗盘榜单接口字段（排名/热度/GMV）需用户登录罗盘配合抓包确认；百应 pack_detail 销量字段待实测
- 决策阈值待用户定义（营业额"高"标准、销量上升幅度、榜单取前 N）
- 建议推进顺序：罗盘②~⑥（榜单数据源）→ 候选池+快照表 → 决策引擎 → 选品看板 UI

## 五、硬约束（不可违反）

1. Python 引擎必须经主进程 child_process 子进程调用；NDJSON(stdout) 传进度；取消用 taskkill /T /F；仅白名单引擎脚本；异常转可读中文
2. 登录凭证用 Electron safeStorage(DPAPI) 加密落盘；stdin 传引擎不落盘
3. 账号分区隔离：抖音 `persist:acct-{id}`、千川 `persist:qc-{id}`、罗盘 `persist:compass-login`、其余 `persist:douyin-login`；每账号独立稳定浏览器指纹
4. **不逆向平台签名逻辑**（风控/合规红线）；不做 GPU 相关投入
5. 下载需间隔随机限速 + 并发配置 + 断点续传（SQLite）；SQLite 用 check_same_thread=False，新增表走增量迁移
6. 新增依赖先说明原因；抖音/头条下载请求必须带 iPhone Safari UA + Referer（否则 CDN 限流降速）
7. 外站链接一律系统浏览器打开（内置视图仅登录类）
8. 打包时 engine 须整体复制全部子目录（extractors 等）
