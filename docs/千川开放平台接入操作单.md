## 甲方需完成的步骤

### 1. 注册巨量引擎开放平台账号

1. 打开 **https://open.oceanengine.com**（巨量引擎开放平台）。
2. 用**千川投放账号同主体的手机号/企业账号**登录注册。
3. 完成开发者主体认证（个人/企业，按实际主体选）。

### 2. 创建应用（关键：类型必须选对）

1. 登录后进入 **控制台**（页面右上角「控制台」入口）。
2. 左侧菜单「**应用管理 / 我的应用**」→ 点击「**创建应用**」。
3. 应用类型务必选择：**「自研投放应用 - 客户」**（对应广告主自研接入；若平台按「巨量千川」归类，则选千川/投放应用类目下的**客户自研**类型）。
4. 填写应用信息：
   - **应用名称**：投广管理客户端
   - **所属行业 / 用途说明**：电商选品 · 商品带货视频素材管理
   - **回调地址（Redirect URI）**：**`http://127.0.0.1:8899/callback`**（开发方已定值）。⚠️ 注册后该地址与端口**不要改动**；平台校验时要求与授权链接里的 `redirect_uri` **完全一致**（授权链接中需做 URL 编码：`http%3A%2F%2F127.0.0.1%3A8899%2Fcallback`）。若平台校验拒绝本机 127.0.0.1 地址，会另行告知替代方案（本机域名），届时再改。
5. 创建成功后，在「**应用详情**」页顶部或「应用凭证」区复制：
   - **App ID（app_key）**
   - **App Secret（app_secret）**

### 3. 申请接口权限

1. 在应用详情 →「权限管理 / 权限点申请」中申请：
   - 权限点：**素材管理 - 图片与视频管理 - 获取数据**
   - 对应接口：`qianchuan/file/video/aweme/get/`
2. 按平台要求提交申请（可能需要填写使用场景说明），等待审核通过（一般 1~3 个工作日）。

### 4. OAuth 授权（广告主 → 应用）

1. **前提**：授权链接里的 `app_id` 就是第 2 步创建应用拿到的 **App ID**，所以这条链接由开发方在收到 App ID 后生成，再发给甲方；甲方也可按模板自行拼（仅替换 `app_id` 值）：
   `https://open.oceanengine.com/audit/oauth.html?app_id=你的AppID&redirect_uri=http%3A%2F%2F127.0.0.1%3A8899%2Fcallback&state=touguang01`
2. 甲方用**千川投放账号（阿凯&长旺MA）**打开授权链接并登录。
3. 页面展示「是否允许该应用访问你的千川数据」→ 点「**同意授权**」。
4. 授权成功后浏览器跳转到 `http://127.0.0.1:8899/callback?auth_code=xxx`；**本地没有客户端运行时页面会显示「无法访问」——这是正常现象**。两种情况：
   - 客户端正在运行（开发方侧）：会自动捕获 `auth_code` 完成换 token；
   - 客户端未运行：请甲方**复制跳转后地址栏完整 URL**（含 `auth_code=...`）发给开发方，由开发方换 token。

## 注意事项

- **多千川账号**：应用（App ID / App Secret）**只需创建一次**，不要每个账号建应用；OAuth 授权是**账户级**的——每个需要接入的千川账号各自做一次「同意授权」（同一个授权链接，用不同千川账号登录即可）。是否全量接入由甲方定，建议先试点核心账号（如「阿凯&长旺MA」）跑通，再批量加。
- 应用类型选错会导致无法申请千川接口权限，务必选「客户/广告主自研」类型。
- 权限点申请需审核，请预留 1~3 个工作日。
- Access Token 会过期，接入时开发方会做「client_token / 用户 token 自动刷新」，甲方无需手工续。
- 该接口能力边界：按 `aweme_id`（指定抖音号）+ `product_id`（商品 ID）过滤，返回该抖音号发过的、挂载该商品的视频——覆盖「自己账号下的该商品带货素材」。
