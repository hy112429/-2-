### 3. 申请接口权限

截图中显示的「客户管理」「巨量引擎工作台管理」不是当前视频查询接口的目标权限。若 OAuth 授权的是抖店账户，自动发现其下千川广告主还要调用 `qianchuan/shop/advertiser/list/`；本次真实调用已返回 `40002` 无权限。优先在授权页直接勾选目标「千川号」；若该标签无法选择目标账户，则核对「店铺账号管理」下这个列表接口的只读权限及店铺授权范围。视频查询本身继续核对「素材管理」下的目标权限。

1. 在应用详情 →「权限管理 / 权限点申请」中申请：
   - 权限点：**素材管理 - 图片与视频管理 - 获取数据**
   - 对应接口：`qianchuan/file/video/aweme/get/`
   - 若使用巨量引擎工作台管理员作为中枢账号，再申请**工作台账户管理 - 获取工作台下账户列表**，对应 `customer_center/advertiser/list/`；客户端以 `account_source=QIANCHUAN` 读取该管理账号可操作的千川广告主。该权限没有获批时，中枢不能自动遍历工作台子账户。
   - 若要让客户端自动列出可用抖音号，还需核对 `qianchuan/aweme/authorized/get/`（获取已授权抖音号）的对应只读权限及目标千川账户是否已勾选授权；当前授权真实调用此接口返回 `40002` 无权限，原因可能是未授权目标千川业务账户。具体权限点名称以平台该接口文档为准。若已有合法千川账户但缺此接口权限，也可手动输入已确认的抖音号 ID。
2. 按平台要求提交申请（可能需要填写使用场景说明），等待审核通过（一般 1~3 个工作日）。

后续若需千川广告消耗、点击、成交或 ROI，另按所选千川报表接口申请相应只读报表权限；「店铺账号管理」只用于店铺账户信息或其下千川广告账户的关联查询，不能代替经营报表权限。若需全店订单、商品销售、售后或账单数据，应另评估抖店开放平台的商家自研应用、店铺授权及对应接口权限，不能只靠本千川应用的素材查询权限。

若要在上传后跟踪视频品质，应另核对「获取视频素材评估标签（新版）」接口 `/open_api/2/file/material_attributes/list/` 的权限点：[官方 Go SDK](https://github.com/oceanengine/ad_open_sdk_go/blob/master/models/model_file_material_attributes_list_v2_response_data_materials_inner.go)列有千川优质、千川低质、低效及低质原因字段；标签可能晚于上传产生，不能把未返回标签视作审核通过。审核通过/拒绝与品质标签是不同结果；需按视频最终进入的千川投放场景核对其审核状态查询接口。截图中的「数据报表 → 获取素材报表」是投放效果数据，不应代替审核或品质接口。当前尚未核实开放平台权限树中上述两个目标接口对应的精确勾选项，申请时以接口文档的「权限点及应用类型」为准。

### 4. OAuth 授权（广告主 → 应用）

在开发版「商品查询与下载」展开「千川开放平台 · 按商品 ID 查询视频」：

1. 在本机输入 App ID、App Secret，点击「保存应用凭证」。凭证经 Electron safeStorage 加密，保存在当前 Windows 用户的客户端数据目录。不要发送到聊天或截图。
2. 从巨量开放平台应用详情复制该应用的**授权 URL**（千川应用可能给出 `https://qianchuan.jinritemai.com/openapi/qc/audit/oauth.html?...`），粘贴到客户端，点击「从本客户端打开授权」。客户端会将 URL 中示例 `state` 替换为随机值，启动 `127.0.0.1:8899` 本机回调监听（最多 15 分钟），并在 Microsoft Edge 默认用户资料中打开授权页，复用 Edge 已有登录态。Chrome 与 Edge 登录态互不共享；授权回调仍须由客户端本次发起并接收。若 Edge 当前登录的是“熊2”，请先在该授权页使用「更换账号授权」切换到目标授权账号，或在 Edge 登录目标账号后重新从客户端发起授权。不要直接在浏览器粘贴原始 URL。
3. 授权页左侧为**应用所属主体**，页面右上角为**当前 Edge 页面登录的授权用户**，两者可以不同。右上角显示“熊2”本身不代表授权失败；关键是该用户有权访问目标千川广告主，并将“倩姐严选”对应的千川广告主纳入本次授权范围。若要切换当前登录用户，使用账号卡片旁的「更换账号授权」。工作台管理员/操作员可通过 `GET /open_api/2/customer_center/advertiser/list/`（`cc_account_id`、`account_source=QIANCHUAN`）展开；抖店账户通过 `qianchuan/shop/advertiser/list/` 展开；也可以直接勾选千川业务账户。工作台列表接口权限不足时，应申请工作台账户列表只读权限，或直接勾选目标千川广告主。只勾选工作台账户但没有相应列表权限，不能假定客户端已能访问其下全部千川账户。「千川号」标签中标为“抖音号管理员”的账号不是视频接口所需的千川广告主 ID。点击页面底部「确认授权」，浏览器回调成功后客户端会自动刷新。
4. 日常使用只需输入商品 ID 并点击「查询视频」。客户端设计为中枢下载器：遍历 OAuth 返回的全部已授权千川广告主，并逐个读取其已授权抖音号，再按「广告主 ID + 抖音号 ID + 商品 ID」调用视频接口；结果标注来源账户。若自动读取抖音号接口未获授权，可在高级选项手动指定抖音号 ID。点击结果旁的「下载验证」后，视频保存至当前下载目录下的「千川视频\\商品ID\\广告主ID」文件夹，并验证 MP4。

仅应用审核通过不代表广告主账户已授权。若授权 URL 不含 `state` 往返回、平台拒绝本机回调、或 URL 查询返回权限错误，应记录具体错误后按当时平台文档调整；不要绕过 `state` 校验。

## 注意事项

- **中枢下载账号**：一个 OAuth 授权流程可以覆盖多个账户；要供下载器检索的每个千川广告主都必须出现在这次授权可访问的账户清单中。若授权用户的工作台/店铺管理关系覆盖全部目标账户，可一次授权管理账户，再申请相应只读列表权限供客户端展开子账户；客户端只遍历接口确认返回的账户，不会跨出授权边界。不同客户主体或未纳入管理关系的账户仍需各自获得授权。
- 应用类型选错会导致无法申请千川接口权限，务必选「客户/广告主自研」类型。
- 权限点申请需审核，请预留 1~3 个工作日。
- Access Token 到期前，客户端会使用 refresh_token 自动刷新并保存轮换后的 Token。授权超期需重新授权。
- 该接口能力边界：按 `aweme_id`（指定抖音号）+ `product_id`（商品 ID）过滤，返回该抖音号发过的、挂载该商品的视频——覆盖「自己账号下的该商品带货素材」。
